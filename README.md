# 🏎️ F1 Dashboard - Power BI

## 📊 Overview

This project is an interactive Power BI dashboard analyzing Formula 1 data from 1950–2024.

It focuses on driver performance, consistency, and long-term trends.

---

## 🚀 Key Features

* Dynamic filtering (Season, Team, Circuit)
* KPI Cards (Total Points, Wins, Podiums, Avg Finish)
* Tooltip-based insights (hover for driver stats)
* Top 10 driver comparison
* Trend analysis over seasons

---

## 🔍 Key Insight

> Consistency matters more than speed
> Top drivers maintain lower average finish positions while achieving higher points.

---

## 🛠️ Tools Used

* Power BI
* DAX
* Data Modeling
